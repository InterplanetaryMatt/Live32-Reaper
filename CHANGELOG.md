# Changelog

## v1.2.1-beta — Public beta candidate

### Monitor and routing
- Dedicated Live32 Monitor/Solo bus.
- Live32 Solo no longer uses REAPER solo-in-place for normal console operation.
- Channel PFL/AFL option.
- Mix Bus AFL option.
- DCA AFL option.
- Select Follows Solo.
- DIM for PFL.
- Monitor level and DIM attenuation controls.
- Hardware routing pages for Main/Monitor, buses and matrices.

### Console architecture
- 32 inputs, 8 FX returns, 16 buses, 8 matrices, 8 DCAs and 6 mute groups.
- Main LR and Matrix routing.
- Sends on Faders with channel→bus and bus/selected-channel views.
- Stereo-link behaviour for odd/even channels and buses.
- Subgroup assignment workflow.

### DSP
- 24 dB/oct channel low-cut.
- 4-band input/FX EQ.
- 6-band bus/Main EQ.
- Gate and compressor with key filter/source controls.
- Real COMP and GATE activity indicators.
- RTA overlay.

### Effects
- Plate, Hall, one-shot Ping-Pong Delay and Chorus send FX.
- Precision Limiter insert.
- 31-band GEQ insert.
- FET 76-style compressor insert.
- Opto 2A-style leveler insert.

### Project workflow
- Launcher with New Console, Attach Project, Import Multitrack and Training Template.
- Repair/complete path for older Live32 projects.
- Scenes and recall safe.
- Renameable/colourable channels, buses, DCAs and Main LR.

### Public-release changes
- Replaced manufacturer-style top branding with independent Live32 branding.
- Added public-beta documentation, licence, contribution guide and issue templates.
