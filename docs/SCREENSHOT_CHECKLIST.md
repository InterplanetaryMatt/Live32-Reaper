# Screenshot / Launch Media Checklist

For the public launch, capture these from the **current v1.2.1 build** so the screenshots accurately represent the release.

1. **Hero — full console**
   - 32-channel layer visible.
   - Scribble strips named/coloured.
   - Main LR and output layer visible.
   - LCD on HOME.
   - Aim for 1600 px+ width if possible.

2. **EQ page**
   - Yellow filled response curve.
   - RTA visible.
   - Low-cut and EQ band cards visible.

3. **Monitor page**
   - PFL/AFL options visible.
   - Monitor level / DIM visible.
   - This is an important v1.2 feature.

4. **Routing page**
   - MAIN/MON hardware patch page.
   - Useful for explaining the live-console architecture.

5. **FX / Inserts**
   - One screenshot of FET 76 or Opto 2A.
   - One screenshot of Plate/Hall or Ping-Pong Delay.

Recommended filenames:

- `live32-full-console.png`
- `live32-eq-rta.png`
- `live32-monitor.png`
- `live32-routing.png`
- `live32-insert-fx.png`

Do not use screenshots showing older UI bugs or manufacturer logos. Use the independent **LIVE32** branding in the public build.
