# Live32 v1.2.1-beta

First public-beta candidate.

## Headline feature

Live32 v1.2 introduces a dedicated Monitor/Solo architecture. Live32 Solo buttons no longer need to interrupt Main LR: channels can be listened to PFL/AFL and buses/DCAs can be monitored AFL through a separate Monitor L/R output path.

## Also included

- 32-channel console architecture with FX returns, buses, matrices, DCAs and mute groups.
- 24 dB/oct low-cut.
- 4-band channel EQ / 6-band output EQ.
- Bus pre/post/subgroup modes.
- Scenes, RTA and stereo linking.
- Dedicated effects and four insert processors.
- Hardware output patching.
- Launcher for new/existing multitrack projects.

## Beta warning

Please use copies of important projects. This release is intended for public testing and bug finding.

## Branding

The public build uses independent Live32 branding. It is not an official Midas/Music Tribe product.
