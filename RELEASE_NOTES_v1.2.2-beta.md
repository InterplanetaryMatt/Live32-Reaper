# Live32 v1.2.2-beta

Public-beta update adding an optional DAW-style Solo mode for stereo-only interfaces.

## Headline feature

Live32 v1.2.2 keeps the dedicated Console PFL/AFL Monitor path as the default, and adds an optional **DAW Solo - use Main L/R** mode. This lets users with only a two-output/stereo interface audition Solo through their normal Main output without configuring a separate monitor pair.

## Solo modes

- **Console Solo (default):** separate Monitor/Solo bus; Main/FOH remains untouched.
- **DAW Solo:** REAPER native solo-in-place through Main L/R; no separate monitor hardware output required.

## Also included

- 32-channel console architecture with FX returns, buses, matrices, DCAs and mute groups.
- 24 dB/oct low-cut.
- 4-band channel EQ / 6-band output EQ.
- Bus pre/post/subgroup modes.
- Scenes, RTA and stereo linking.
- Dedicated effects and four insert processors.
- Hardware output patching.
- Launcher for new/existing multitrack projects.

Please use copies of important projects. This release is intended for public testing and bug finding.
